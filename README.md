# ITechmobile React

Réplica em React/Vite da estrutura pública atual do itechmobile.pt, mantendo o conceito visual de loja/acessórios e reparação, mas com a nova cor azul como destaque.

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy Netlify

Build command: `npm run build`
Publish directory: `dist`

O formulário de contacto está preparado para Netlify Forms.
